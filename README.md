# ForgeFit

ForgeFit is a modern fitness brand landing page built for a premium gym experience. The project showcases a strong visual identity, responsive sections, and conversion-focused messaging designed to attract memberships and promote facilities.

**Live Demo:** https://forgefit-muscle-fitness-center.vercel.app/

## Overview

This project was designed as a premium single-page experience for a fitness center, combining a dark, high-contrast aesthetic with clean typography and polished motion cues. The layout highlights key brand messages around strength, coaching, and transformation while remaining easy to navigate across devices.

## Key Updates

- Refined hero messaging to better communicate the brand position and value proposition
- Added a subtle dark grain/noise texture for a richer premium UI feel
- Improved overall presentation with a more polished dark theme and stronger contrast
- Added a scroll-to-top interaction that feels intentional and brand-consistent
- Kept the design responsive and clean across desktop and mobile layouts

## Features

- Responsive single-page layout
- Premium gym-focused branding and styling
- Strong hero section with conversion-driven calls-to-action
- About, memberships, facilities, and contact sections
- Scroll-to-top button for smoother UX
- Dark-mode luxury aesthetic with subtle texture overlays
